# UI・コンポーネント設計

## デザイン方針

- スマホファーストで、会計時に片手で操作しやすいUIにします。
- 背景は暗めにし、黄色、オレンジ、赤系をアクセントに使います。
- 居酒屋、飲み会、ガチャ感を感じる文言と演出を入れます。
- ボタンは大きく、押下領域を十分に確保します。
- 結果はカード形式で、誰がいくら払うかを瞬時に読めるようにします。
- PC表示では中央寄せの最大幅レイアウトにし、横に伸びすぎないようにします。

## レイアウト方針

| 画面 | レイアウト |
| --- | --- |
| トップ | 縦積み、モードボタンを大きな選択肢として表示 |
| 入力 | フォームを上から順に入力できる1カラム構成 |
| 結果 | 合計金額を上部に強調し、支払いカードを縦に並べる |

## Tailwind CSS方針

- 背景: `bg-zinc-950`、`bg-stone-950`などの暗色
- カード: `bg-zinc-900`、`border-orange-500/30`
- アクセント: `text-yellow-300`、`bg-orange-500`、`bg-red-600`
- ボタン: 高さ48px以上を目安にする
- 角丸: カードやボタンは過度に丸くしすぎず、8px前後を基本にする
- フォーカス: キーボード操作でも分かるリングを付ける

## コンポーネント案

| コンポーネント | 責務 |
| --- | --- |
| `TopScreen` | アプリ名、キャッチコピー、4つのモード選択ボタンを表示する |
| `InputScreen` | 共通入力、モード別設定、バリデーションエラーを表示する |
| `MemberFields` | 人数分のメンバー名入力欄と立場選択を表示する |
| `ModeSpecificSettings` | ランダム強度などモード固有設定を表示する |
| `ResultScreen` | 計算結果、再計算、条件変更、コピー、X共有を提供する |
| `PaymentCard` | メンバーごとの支払い額、立場、倍率、端数負担者ラベルを表示する |

## アクセシビリティ

- フォーム項目には`label`を関連付ける。
- エラー文は入力欄の近くに表示する。
- ボタン文言は操作内容が分かるものにする。
- 色だけで端数負担者を表現せず、ラベルでも示す。
- X共有など外部リンクは分かる文言にする。

## 文言案

### トップ

- キャッチコピー: 会計の空気を、ちょっと楽しく。
- 補足: 金額を入れて、モードを選んで、運命の割り勘へ。

### ボタン

- 計算する
- もう一度ガチャる
- 条件を変更
- 結果をコピー
- Xで共有
- トップに戻る

### 結果強調

- 端数担当
- 今日のラッキー会計係
- ガチャ結果
