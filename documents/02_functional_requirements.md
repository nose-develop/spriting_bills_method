# 機能要件設計

## 共通機能

### 入力管理

- 入力内容はReact stateで管理します。
- 画面遷移もstateで管理し、URLルーティングは必須にしません。
- メンバー情報は人数に合わせて配列で保持します。

### データ型案

```ts
type SplitMode = "normal" | "weighted" | "random" | "roulette";
type RoundingUnit = 1 | 10 | 100;
type MemberRole = "boss" | "senior" | "peer" | "junior" | "student";
type RandomIntensity = "gentle" | "normal" | "hell";

type MemberInput = {
  id: string;
  name: string;
  role: MemberRole;
};

type PaymentResult = {
  memberId: string;
  name: string;
  role?: MemberRole;
  weight?: number;
  amount: number;
  isRemainderPayer?: boolean;
};
```

## 通常割り勘

### 仕様

- 合計金額を人数で均等に割ります。
- 端数処理単位に応じて、基準額を切り捨てます。
- 切り捨てで生じた差額を端数として扱います。
- 端数負担者をランダムで1人決定します。
- 支払い合計は必ず合計金額と一致させます。

## 上司多め割り勘

### 立場と倍率

| 立場 | 値 | 倍率 |
| --- | --- | --- |
| 上司 | boss | 1.6 |
| 先輩 | senior | 1.2 |
| 同期 | peer | 1.0 |
| 後輩 | junior | 0.8 |
| 学生 | student | 0.6 |

### 仕様

- 各メンバーの倍率合計を算出します。
- `合計金額 * 個人倍率 / 倍率合計`で仮の支払い額を算出します。
- 端数処理単位で丸めます。
- 丸め後の差額を調整し、合計金額と一致させます。
- 結果には名前、立場、倍率、支払い金額を表示します。

## 完全ランダム割り勘

### 強度

| 強度 | 方針 |
| --- | --- |
| やさしい | 均等割りからのブレ幅を小さくする |
| 普通 | 中程度のブレ幅で配分する |
| 地獄 | 大きなブレ幅を許容する |

### 仕様

- 合計金額は必ず一致させます。
- 各メンバーの支払い額をランダムに決定します。
- 0円の人は出しません。
- 端数処理単位に沿った金額にします。
- 再抽選ボタンで同じ条件のまま再計算できます。
- 結果にランダムコメントを表示します。

## 端数ルーレット

### 仕様

- 通常割り勘をベースに計算します。
- 端数が発生した場合、端数負担者をランダムで1人選びます。
- 端数負担者をカード、ラベル、色、演出で目立たせます。
- 可能であれば、結果表示前または結果画面内で簡単なルーレット風演出を行います。

## コピー機能

- `navigator.clipboard.writeText`を利用します。
- コピー文面にはアプリ名、モード名、合計金額、各メンバーの支払い金額、コメントを含めます。
- 成功時は「コピーしました」を表示します。
- 失敗時は「コピーできませんでした」を表示します。

## X共有

- `https://twitter.com/intent/tweet?text=...`形式のURLを生成します。
- 結果テキストは長くなりすぎないように整形します。
- 外部API連携は行いません。
